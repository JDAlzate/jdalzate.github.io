The following docs are a combination of the personal notes I'm currently taking for [Stephen Ulibarri's Gameplay Ability System course](https://www.udemy.com/course/unreal-engine-5-gas-top-down-rpg/), along with anything else I learn while using GAS for my own projects. I'm publishing in case they are useful to someone else, but note that they're not meant to be professional documentation.

If you want to learn GAS, I highly recommend Stephen's course. There's nothing else like it.

For additional GAS reference, you should definitely check out [Tranek's Documentation](https://github.com/tranek/GASDocumentation) on GitHub. He's been documenting GAS for a really long time.

**Heads up**: throughout this documentation, if you want to hide the table of contents on the right to make more room for the text, you can simply click on the table of contents heading!
